# Data Handling and Infrastructure for AI

An induction to the module, its practical focus, and the infrastructure mindset needed for successful AI/ML delivery.

## Why this module matters

Modern AI systems depend on much more than models. They require reliable data, repeatable pipelines, suitable storage, operational monitoring, and infrastructure that can scale from notebooks to production-grade platforms.

This module introduces those foundations so you can move from experimenting with AI to building systems that are robust, efficient, and maintainable.

## Indicative module themes

- Data types for AI: tabular, graph, and unstructured data
- Feature engineering, statistics, and model-building foundations
- Data pipelines using notebook workflows, ETL processes, and batch vs streaming approaches
- Context-aware AI system design and explicit model operation patterns
- Data storage for AI: SQL, NoSQL, data lakes, and cloud warehouses
- AI/ML Ops practices: versioning, monitoring, CI/CD, and community platforms
- High-performance computing with distributed systems, GPUs, and TPUs
- Efficient processing of large-scale AI datasets using modern frameworks
- Cloud infrastructure for AI on AWS, GCP, and Azure
- Scalable model training patterns for large language models

## Learning outcomes

By the end of the module, you should be able to:

1. Critically compare different data types and explain the role of feature engineering and statistics in AI/ML.
2. Design and implement data pipelines using tools such as Jupyter Notebook, and distinguish between batch and streaming approaches.
3. Critically evaluate modern GenAI patterns and their use in AI/ML projects.
4. Compare data storage solutions and judge their suitability for different AI/ML applications.
5. Apply AI/ML Ops principles, including versioning, monitoring, and CI/CD practices, using industry platforms.
6. Use high-performance computing resources for efficient data processing and model training.
7. Develop scalable infrastructure strategies for training large language models on cloud platforms.

## How you will learn

- Live online lectures to frame concepts and connect theory to practice
- Self-paced practical labs using AI and ML tools with lecturer support
- Case studies focused on deep learning and real deployment constraints
- Online communication channels for lecturer and peer support
- Asynchronous materials for independent study and revision

## Assessment snapshot

Continuous assessment accounts for 100% of the module:

- In-class assessment: 50% (aligned with outcomes 1, 2, and 3)
- Assignment: 50% (aligned with outcomes 1, 4, and 5)

Strong performance in this module means not just understanding concepts, but demonstrating secure, scalable, and maintainable data and infrastructure decisions.

## Core tools and platforms

Across the module you can expect to work with or discuss:

- Jupyter Notebook environments
- ETL and data workflow patterns
- SQL and NoSQL storage options
- Data lakes and cloud data warehouses
- Hugging Face and Kaggle style AI/ML ecosystems
- PyTorch for large-scale dataset and model workflows
- Cloud platforms such as AWS, GCP, and Azure
- GPU and TPU-backed compute environments

## What to focus on from the start

As you begin the module, aim to build good habits in four areas:

1. **Data awareness** - understand the structure, quality, and limitations of the data you use.
2. **Pipeline thinking** - treat every transformation as part of a reproducible workflow.
3. **Operational discipline** - version work, monitor behaviour, and document assumptions.
4. **Infrastructure judgement** - choose tools and platforms that fit scale, cost, and performance needs.

## Recommended mindset

Think like an engineer as well as a model builder. The best AI solutions are not just accurate: they are traceable, repeatable, resource-aware, and deployable.
